# HRMS Web App

A modern, full-stack **Human Resource Management System (HRMS)** designed to simplify employee management, attendance tracking, leave management, payroll processing and HR operations through a secure and user-friendly web application.

## 🚀 Overview

HRMD Web App helps organizations manage daily HR activities from a centralized platform. It provides separate role-based experiences for HR and employees, making it easier to manage employee information, monitor attendance, process payroll and access important HR records.

## ✨ Features

### 🔐 Authentication & Authorization
- Secure login system
- JWT-based authentication
- Password encryption using bcrypt
- Role-based access control
- HR and Employee portal access

### 👨‍💼 HR Portal
- HR dashboard
- Employee management
- Employee onboarding
- Employee attendance monitoring
- Leave request management
- Payroll processing
- Payslip management
- Notifications and reports
- Search and filtering functionality

### 👨‍💻 Employee Portal
- Employee dashboard
- View profile and personal details
- Check-in and check-out
- Attendance history
- Working hours tracking
- Leave application and tracking
- View payroll and payslips
- Access notifications

### 📊 Attendance Management
- Employee check-in and check-out
- Daily attendance tracking
- Attendance history
- Working hours calculation
- Overtime tracking
- HR attendance overview

### 💰 Payroll Management
- Create and manage payroll records
- View employee payroll details
- Access payslips
- Download payslip documents
- Secure payroll actions
